# Store-Operations-Data-Analysis
Projects showcasing data analysis using PostgreSQL and Power BI to drive operational efficiency.

📊 Retail Operations Analysis & KPI Dashboard
Strategic Optimization of Labor Costs and Inventory Waste

📝 Project Overview
This project demonstrates a data-driven approach to retail management, bridging the gap between store-level operations and executive-level analytics. Utilizing PostgreSQL for data engineering and Power BI for visualization, I developed a framework to monitor performance across multiple Australian regions including NSW, VIC, and QLD.

🚀 Business Impact & Results
By implementing this tracking system, I successfully managed core operational metrics to hit high-efficiency targets:

Labor Cost Optimization: Successfully maintained a 28% labor-to-sales ratio, a significant improvement from the 34% baseline.

Waste Mitigation: Achieved a 1.4% food waste metric through precise inventory tracking, down from 2%.

Profitability Oversight: Provided real-time visibility into total store profits, which reached $601.30K.

🛠️ Technical Implementation
1. Data Engineering (PostgreSQL)
I designed a relational database to automate the evaluation of store health.

Schema Design: Engineered stores and daily_metrics tables with optimized data types for financial reporting.

Automated KPI Logic: Developed SQL scripts using CASE statements to instantly categorize store status as "TARGET MET" or "OVER BUDGET".

Data Integrity: Implemented foreign key relationships to ensure sales data remains linked to the correct suburb and state.

2. Business Intelligence (Power BI)
Interactive Filtering: Designed slicers to allow stakeholders to view performance by specific suburb (e.g., Sydney Town Hall, Burwood, Vermont South).

Conditional Formatting: Integrated visual indicators (Green/Red) to highlight which locations are meeting labor and waste targets.

Data Aggregation: Created measures to calculate total regional performance across different Australian states.

SQL Development: Table creation, data insertion, and complex logic.

Data Storytelling: Translating raw financial numbers into actionable visual insights.

Business Acumen: Deep understanding of retail KPIs like labor percentage and food waste.
